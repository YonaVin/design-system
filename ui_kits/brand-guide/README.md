# Gurufin Brand Guide UI Kit

A high-fidelity recreation of core Gurufin product UI screens, based on the Brand Guidelines v1.0 (2026).

## Screens included in index.html

1. **Dashboard** — dark navy, KPI cards, transaction list
2. **Wallet / Send** — form on dark with GX amount input
3. **Chain Explorer** — block list on dark bg

## Design Notes
- Dark theme is primary (deep navy `#070F1A`)
- Light theme available for content/form-heavy screens (`#F5F8FF`)
- Primary typeface: Helvetica Neue
- All monetary values use monospace font
- Cards: `border-radius: 20px`, glass effect on dark
- Page margin: 100px (scaled down in UI kit for viewport)
